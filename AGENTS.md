# Obsidian Markdown Skill

## Purpose

Create and edit Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties, and other Obsidian-specific syntax.

## When to Use

- Creating new Obsidian notes with specific formatting.
- Editing existing notes to add Obsidian-specific features.
- Converting standard Markdown to Obsidian Flavored Markdown.
- Answering questions about Obsidian syntax.

## Key Features

- **Wikilinks**: `[[Note Name]]`, `[[Note Name#Heading]]`
- **Embeds**: `![[Note Name]]`, `![[image.png]]`
- **Callouts**: `> [!note]`, `> [!tip]`
- **Properties**: YAML frontmatter for metadata.
- **Tags**: `#tag`, `#nested/tag`
