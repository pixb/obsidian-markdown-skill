# Obsidian Markdown Skill

A skill for creating and editing Obsidian Flavored Markdown.

## Features

- **Wikilinks**: `[[Note Name]]`, `[[Note Name#Heading]]`
- **Embeds**: `![[Note Name]]`, `![[image.png]]`
- **Callouts**: `> [!note]`, `> [!tip]`
- **Properties**: YAML frontmatter for metadata.
- **Tags**: `#tag`, `#nested/tag`

## Installation

### For Opencode

```bash
cp -r obsidian-markdown-skill ~/.config/opencode/skills/
```

### For Cursor

```bash
cp -r obsidian-markdown-skill ~/.cursor/skills/
```

## Usage

- "Create a new note in Obsidian format with a task list."
- "Edit my daily note to add a callout for an important event."
- "Convert this standard Markdown to Obsidian Flavored Markdown."
- "How do I link to a specific heading in another note?"
